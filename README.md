# FINAL-PROJECT-OOP
Development of a Python-Based Financial Performance Analytics for Examining Credit, Economic Policies and Market Competition in Financial Institutions in Uganda.

This final project demonstrates my Object-Oriented Programming (OOP) skills in Python through the development of a financial performance analytics dashboard focused on financial institutions in Uganda, including microfinance institutions, money lenders, and other credit providers.

The project applies core OOP principles such as encapsulation, abstraction, inheritance, and polymorphism to design modular, reusable, and maintainable Python code. Classes and objects will be used to represent financial institutions, credit facilities, economic policy indicators, and financial performance metrics.

The dashboard aims to analyse credit performance, interest rates, loan repayment trends, economic policy effects, and market competition. It will transform financial data into meaningful visualisations and analytical insights to support the evaluation of financial institutions and their role in Uganda's financial sector.

Through this project, I demonstrate my ability to apply Python programming, data analysis, financial analytics, and software design principles to a practical financial problem. GitHub will showcase the project's source code, class structures, implementation of OOP concepts, documentation, and development progress, providing evidence of my programming skills and ability to develop a structured, data-driven analytical application.

Key technologies: Python, Object-Oriented Programming, Pandas, Matplotlib, Seaborn, and Streamlit.
